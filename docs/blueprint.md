# **App Name**: CourtFind

## Core Features:

- Location Detection: Automatically detect the user's current location using GPS.
- Court Search and Filtering: Allow users to search for available courts based on sport type, date, time, distance, and other criteria.
- Court Availability Display: Display real-time availability of each court, including hourly time slots.
- Smart Suggestion: Use AI tool to provide suggestions for nearby alternatives with open slots.
- Court Booking: Enable users to reserve or book a court slot.
- Court Details: Display court details, including address, surface type, lighting, amenities, pricing, rules, and operating hours.
- User Authentication: Allow users to sign up and manage bookings using their existing Google account or Apple ID.

## Style Guidelines:

- Primary color: A vibrant green (#2ecc71) for main buttons and highlights, inspired by the 'TODAY' button.
- Secondary color: A desaturated light green (#ecf0f1) for backgrounds and card-like elements, mirroring the general background tone.
- Accent color: A darker shade of green (#27ae60) for active states and selected filters, complementing the primary color.
- Body and headline font: Use a clean and modern sans-serif font like 'Open Sans' or 'Lato' for readability.
- Use simple, geometric icons to represent different sports and amenities, similar to the filter icon.
- Implement a clean, mobile-first UX with a map view and list view, using a card-based layout for court listings.
- Use subtle transitions and animations to provide feedback and enhance the user experience.
